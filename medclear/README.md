> 感知 → 推理 → 决策：上传一份体检报告，三步读懂全部指标并生成可执行的健康行动方案。
>

## 作品简介

明检 MedClear 面向"体检报告看不懂、异常指标被忽视、复查无人提醒"这一普遍痛点，构建了一条清晰、可演示的 AI 能力闭环：

- **感知（Perceive）**：识别体检报告版式，抽取检验项目、数值、单位与参考区间，结构化为标准指标数据。
- **推理（Reason）**：按性别与年龄匹配参考区间判定异常与危急值；调用医学知识库进行多指标交叉推理（如 ALT+AST+GGT→肝胆损伤、BMI+血压+血糖+血脂→代谢综合征），并完成器官系统风险建模与历年趋势分析。
- **决策（Decide）**：输出分级风险结论、个性化复查计划、就诊科室建议、生活方式干预与家庭行动计划。

产品以"家庭"为管理单元，支持自由添加、编辑、删除家庭成员并为每位成员建档，集中呈现全家健康风险矩阵，并可将体检结论一键转化为带优先级和截止日期的健康任务。所有数据保存在本机浏览器，无需后端即可完整运行。

## 功能模块

| 模块 | 能力 |
| --- | --- |
| 家庭健康总览 | 全家健康评分、器官系统风险矩阵、重点风险提示 |
| 报告智能解读 | 选择成员与报告 → 感知-推理-决策动画 → 健康评分、风险雷达、推理链、异常明细、决策建议、趋势洞察 |
| 报告导入 | 图片 OCR 识别、PDF 文本解析、文本/CSV/JSON 导入、手动录入，解析结果可人工核对修改后保存 |
| 家庭成员档案 | 成员增删改、健康画像、报告归档、历年趋势、异常指标汇总 |
| 复查与行动计划 | 由体检结论自动拆解的任务清单，含优先级、截止日期与完成进度 |
| AI 健康助手 | 多智能体协同问答，针对某一成员的多轮追问与指标解释 |

## 真实可用性

- **成员自由管理**：任意添加/编辑/删除家庭成员，数据持久化到浏览器 localStorage。
- **真实报告导入**：支持上传自己的体检报告（图片走内置 OCR，PDF 走文本层解析），或粘贴文本、导入 CSV/JSON、手动录入指标。
- **人工确认闭环**：AI 识别后展示可编辑的指标清单，用户修正后保存，符合"AI + 人工确认"的半自动协同思路。
- **趋势来自真实数据**：上传 2 份及以上报告后，自动基于归档报告生成跨年度趋势。

## 回答建议引擎：本地规则 与 大模型 双模式

用户可在「设置」中自由切换是否启用大模型增强，两种模式共用同一套健康数据结构：

- **本地规则引擎（默认，离线可用）**：无需密钥、数据不出本机。以个体化、可量化、按优先级排序的方式生成建议——结合年龄/性别/既往史给出控制目标（如 LDL、血压、尿酸、血糖目标），对指标做交叉推理后输出优先行动清单，并给出个体化提醒。
- **大模型增强（可选）**：兼容 OpenAI Chat Completions 协议，内置 OpenAI / DeepSeek / 通义千问 / Kimi 预设，也可自定义 Base URL 与模型。启用后，AI 健康助手问答与报告"深度建议"由大模型基于当前成员的报告数据生成；调用失败会自动降级为本地规则引擎并提示原因。
- **演示模式**：无需密钥即可体验大模型增强的回答形态，便于无网络或未配置密钥时演示。
- **隐私与安全**：API Key 仅保存在本机浏览器 localStorage，由浏览器直接发送至用户填写的服务方，不经任何第三方中转。

## 技术方案

- **前端框架**：Vue 3（`<script setup>`）+ Vite 6
- **可视化**：ECharts（健康评分仪表盘、系统风险雷达、历年趋势折线）
- **架构分层**：
  - `src/data/health.js`：医学指标知识库（参考区间、临床意义、干预建议）
  - `src/data/catalog.js`：指标别名表与目录，支撑任意报告文本识别
  - `src/data/seed.js`：内置示例家庭成员与历史报告
  - `src/engine/analyze.js`：感知-推理-决策分析引擎（异常判定、交叉推理链、系统风险建模、决策生成）
  - `src/engine/parser.js`：文本 / CSV / JSON 报告解析器
  - `src/engine/ingest.js`：OCR 与 PDF 文本提取（按需 CDN 加载，失败可降级为手动录入）
  - `src/engine/advisor.js`：本地规则建议引擎（个体化、可量化、按优先级排序）
  - `src/engine/llm.js`：大模型接入（OpenAI 兼容协议 + 演示模式 + 失败降级）
  - `src/store.js`：本地持久化状态、成员与报告 CRUD、分析聚合
  - `src/views/*`：五大功能视图
  - `src/components/*`：图表、图标、成员编辑与报告导入弹窗
- 设计系统为深色品牌导航 + 浅色医疗风内容区，强调专业、可信、易读。

## 性能与可维护性

- **别名匹配预编译**：`data/catalog.js` 在模块加载时一次性构建别名索引与正则，避免解析每条报告行时重复构造正则；实测 2000 行文本的指标匹配提速约 29 倍。
- **分析结果缓存**：`store.js` 以 `dataRev` 数据版本号对分析结果与历史序列做缓存，同一数据状态下的多次读取直接复用，跨组件共享，成员/报告变更时自动失效。
- **单次遍历聚合**：分析引擎对指标按系统聚合改为一次遍历，避免对每个系统重复过滤；用 `itemByCode` 映射替代多次线性查找。
- **共享常量收敛**：状态/风险等级文案与配色统一收敛到 `utils.js`，消除各视图与引擎中的重复定义。
- **纯函数抽取**：历史序列构建抽取为 `engine/history.js` 纯函数，便于测试与复用。
